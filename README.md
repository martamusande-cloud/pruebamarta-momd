# ¿Qué tardeo eres?

Web móvil con tres preguntas, resultados por tardeo y premio personalizado DESCUENTO50: 50% de descuento para el próximo fin de semana. Paleta crema cálido, coral rojizo, rosa melocotón, amarillo mantequilla y granate oscuro. Las respuestas avanzan automáticamente; Anterior permite corregirlas.

## Abrir y publicar
Abre index.html para usar la copia local. La versión pública está en https://martamusande-cloud.github.io/pruebamarta-momd/ y se publica desde la carpeta tardeo del repositorio.

## Fotos reales

Las ocho imágenes se han optimizado para web sin filtros y están en assets/. Los archivos photo-*.js contienen esas imágenes integradas para que la web sea portable. Para cambiarlas, edita config.js: sustituye image por una ruta como 'assets/mi-foto.webp' y actualiza alt. Las galerías están en gallery, una por marca. Puedes cambiar cada foto de manera independiente.

## Premio y privacidad
Se pide solo el nombre después de las tres preguntas. Se muestra junto al código; no se guarda ni se envía. El resultado muestra primero el tardeo obtenido y después DESCUENTO50, válido también en los otros dos tardeos. No se requiere enviar mensajes ni capturas. Esta web muestra el código promocional; su aceptación se gestiona en los canales de los locales.

## Edición
Textos y preguntas: app.js. Colores, tipografía y disposición: styles.css. Fotos y CTA de ubicación: config.js. Gana la mayoría de respuestas; los empates se resuelven por la respuesta más reciente entre los empatados.
